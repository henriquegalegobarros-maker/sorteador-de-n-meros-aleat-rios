🎲 Sorteador de Números

Projeto desenvolvido durante meus estudos de programação no DevClub, com o objetivo de praticar os fundamentos de HTML, CSS e JavaScript.

🚀 Sobre o projeto

O Sorteador de Números permite que o usuário informe um número inicial e um número final para realizar um sorteio aleatório entre os valores escolhidos.

O resultado é exibido diretamente na tela após clicar no botão Sortear.

🛠️ Tecnologias utilizadas

HTML5: estruturação dos elementos da página.

CSS3: estilização, organização dos elementos e efeitos visuais no botão.

JavaScript: lógica do sorteio, captura dos valores dos inputs e geração de números aleatórios.

📚 O que pratiquei neste projeto

Seleção de elementos com querySelector().

Eventos com addEventListener().

Captura de valores utilizando .value.

Conversão de valores com Number().

Geração de números aleatórios com Math.random().

Utilização de Math.floor() para gerar números inteiros.

💻 Objetivo

Praticar a integração entre HTML, CSS e JavaScript, desenvolvendo uma página interativa e aprimorando meus conhecimentos em lógica de programação.
